# ROKAE Joint Reader

A lightweight read-only utility for checking current joint angles from multiple ROKAE robot controllers.

The tool provides both a Python CLI and a small Tkinter GUI. It connects through the ROKAE Python SDK, reads joint positions and basic controller state, and prints the result in degrees and radians.

## Features

- Read current joint angles from one or more ROKAE controllers
- Show both degree and radian values
- Display basic controller state, including power, operate mode, and operation state
- Optional JSON output for scripts
- Simple GUI with one-shot reading and live refresh
- Read-only behavior: no power, mode, realtime, or motion commands are sent

## Supported Setup

The default configuration is prepared for a wheeled humanoid ROKAE platform with three controllers:

| Target | IP | Robot / Controller | SDK class |
| --- | --- | --- | --- |
| `right_arm` | `192.168.71.160` | `AR5-5_0.7R-W4C1C1` right 7-axis arm | `xMateErProRobot` |
| `left_arm` | `192.168.71.161` | `AR5-5_0.7L-W4C1C1` left 7-axis arm | `xMateErProRobot` |
| `taihu` | `192.168.71.254` | TaiHu body controller | `Robot_T_Industrial_4`, fallback `IndustrialRobot_4` |

Default local host IP:

```text
192.168.71.56
```

## Files

```text
ROKAE_Joint_Reader        # Linux GUI launcher
read_rokae_joints_gui.py  # Tkinter GUI
read_rokae_joints.py      # CLI and SDK reading logic
```

Runtime folders such as `logs/`, `_rokae_log_/`, and `__pycache__/` may be generated by the SDK or Python and are ignored by git.

## Usage

### GUI

Run the launcher:

```bash
./ROKAE_Joint_Reader
```

Or run the GUI directly:

```bash
python read_rokae_joints_gui.py
```

Available targets:

```text
all
right_arm
left_arm
taihu
```

### CLI

Read all configured controllers:

```bash
python read_rokae_joints.py
```

Read one target:

```bash
python read_rokae_joints.py --target right_arm
python read_rokae_joints.py --target left_arm
python read_rokae_joints.py --target taihu
```

Use a custom local host IP:

```bash
python read_rokae_joints.py --host-ip 192.168.71.56
```

Print JSON:

```bash
python read_rokae_joints.py --json
```

Optionally check TCP port 5050 before creating the SDK robot object:

```bash
python read_rokae_joints.py --check-port
```

## Safety

This tool is intended to be read-only. It only:

- creates a SDK robot object
- calls `jointPos()`
- optionally reads `powerState()`, `operateMode()`, and `operationState()`
- prints the result

It does not power on the robot, switch mode, clear alarms, start realtime control, or send motion targets.

## Adapting To Another ROKAE Robot

Most changes are made in `read_rokae_joints.py`.

### 1. Edit controller targets

Update `DEFAULT_TARGETS`:

```python
DEFAULT_TARGETS = (
    RobotTarget(
        name="right_arm",
        ip="192.168.71.160",
        sdk_classes=("xMateErProRobot",),
        joint_labels=("J1", "J2", "J3", "J4", "J5", "J6", "J7"),
    ),
)
```

Set:

- `name`: target name used by `--target`
- `ip`: controller IP address
- `sdk_classes`: SDK class names to try
- `joint_labels`: display labels for each joint

### 2. Edit GUI target list

If targets are added or removed, update the combobox values in `read_rokae_joints_gui.py`:

```python
values=("all", "right_arm", "left_arm", "taihu")
```

### 3. Choose the correct SDK class

The default configuration uses:

```python
xMateErProRobot
Robot_T_Industrial_4
IndustrialRobot_4
```

If a controller may support multiple wrappers, list them in priority order:

```python
sdk_classes=("Robot_T_Industrial_4", "IndustrialRobot_4")
```

The reader will try each class until one succeeds.

## Requirements

- Python 3.10+
- Tkinter for the GUI
- ROKAE Python SDK available in the Python environment
- Network access from the host PC to the robot controller IPs
